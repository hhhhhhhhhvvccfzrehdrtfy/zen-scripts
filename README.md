# zen-scripts
## Animations

- [`animations/sonic-vs-one-punch-man`](animations/sonic-vs-one-punch-man): an 8-minute fan-made cartoon, Sonic vs Saitama, drawn live with HTML canvas. Synthesized sound, no assets. Serve the folder (for example `npx http-server animations/sonic-vs-one-punch-man`) and open `index.html`.
- Round 2 lives in the same folder: a 5-minute sequel where Shadow the Hedgehog crashes the rematch, with hand-keyed fight choreography. Open `round-2.html` from the same server.
- Round 3 lives there too: a 3.5-minute space battle, Hyper Shadic (Sonic and Shadow fused) against Serious Saitama, running nonstop from Earth orbit through the Moon, Mars, the asteroid belt, Jupiter, Saturn and a comet to the Sun. Open `round-3.html`.
